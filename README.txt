Bee Sweet site (storefront + admin, installable PWA)

1. Open config.js and set API_BASE to your Railway server URL.
2. Deploy this folder as its own Railway service (npm start serves it), or upload it to any static host.
3. Storefront: your-site/    Admin: your-site/admin.html
4. Put the final site URL in the server's SITE_URL variable.
5. Install: Android/Chrome shows "Install app" in the menu; on iPhone use Share, then Add to Home Screen.
